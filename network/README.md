# network — 헤드리스 보드 다루기

모니터도 키보드도 없는 CM4를 **주소를 모르는 상태에서** 붙잡기 위한 도구들.
문제는 늘 같다: 새 망에 옮기면 IP가 바뀌고, 바뀐 IP를 알 방법이 없다.

| 파일 | 하는 일 |
|---|---|
| `wifi_add.sh` | Wi-Fi 프로필 추가/수정. 비밀번호는 프롬프트로만 받는다(인자로 받으면 셸 히스토리에 남는다) |
| `wifi_report.py` | 부팅·네트워크 변경 시 현재 IP를 Google Chat 웹훅으로 보고 |
| `setup_cm4.sh` | 새 보드에 위 둘을 설치하고 서비스로 등록 |

## 웹훅은 자격증명이다

URL을 아는 사람은 누구나 그 채널에 글을 쓸 수 있다. 그래서:

- 기기에서는 `/etc/wifi_report.conf` (root 소유, 0600) 한 줄에만 둔다
- 원격 설치 시 **stdin으로** 넘긴다 — 명령줄 인자는 `ps` 에 그대로 보인다
- 이 repo에는 절대 넣지 않는다 (`.gitignore` 가 `*.conf` 를 막는다)

## 왜 웹훅으로 IP를 보고하나

헤드리스 보드를 새 망에 놓으면 주소를 알 방법이 없다. mDNS는 망에 따라 막히고,
스캔은 느리고 사설망 밖에서는 불가능하다. 부팅 때 보드가 **스스로 알려주는** 것이
가장 확실하다. 그래도 안 되는 경우를 위해 `ap-fallback`(SSID `chocs_cm4`)이 안전망으로
남아 있다 — 어느 망에도 못 붙으면 보드가 자기 AP를 띄운다.
